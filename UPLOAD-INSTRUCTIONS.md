# Happy 6 Months — Full Local Soundtrack

Upload every file in this folder to the root of the `happy-6-months` GitHub repository.

Important:
- Do not upload only the HTML/CSS/JS files.
- All eight MP3 files must also be uploaded, or those tracks will not play.
- The first button press starts `valentine.mp3` at about 40 seconds.
- Browsers require that first tap before sound can start.
